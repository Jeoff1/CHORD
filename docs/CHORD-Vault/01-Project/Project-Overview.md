# Project Overview

CHORD is a Django church management system with future ML-powered worship song
recommendations. The development foundation, authentication/RBAC, member
management, choir management, worship song library, worship planning, ministry
management, church-wide events/attendance, giving, official Spotify track
embeds, and protected chord-resource viewing are implemented.

Phase 7 owns dashboards/reports/UI refinement, Phase 8 is the reserved ML recommendation
phase, and Phase 9 owns final security and deployment. No ML recommendation
behavior is implemented or in progress.
